# دیما سینەما - DIMA Cinema 🎬

**سەکۆی سینەمایی پێشەنگ بۆ سەیرکردنی فیلم و زنجیرە جیهانییەکان بە ژێرنووسی کوردی سۆرانی**
Inspired by modern cinematic streaming platforms with a clean, dark aesthetic (#0B0B0F, purple & gold accents), fully RTL, mobile-first, and rich in Kurdish typography.

---

## 🌟 تایبەتمەندییە سەرەکییەکان (Key Features)

- **ڕووکاری تەواو کوردی (Sorani RTL)**:
  - بەکارهێنانی فۆنتی فەرمی Vazirmatn و Noto Sans Arabic بە قەبارەی سینەمایی.
  - گۆڕینی خۆکاری ژمارەکان بۆ ژمارەی کوردی-هیندی (٠١٢٣٤٥٦٧٨٩).
  - تەواوی مێنیو، دوگمە، فلتەر، و پەیامەکان بە کوردی ڕوون و پاراو نووسراون.
- **سیستەمی پێشکەوتووی پەخش (The Custom Player Shell)**:
  - 16:9 کانتینەری تاریک بە چرپەی وەنەوشەیی و بارکردنی تەمەڵ (Lazy-loading) بە پۆستەری گەورە.
  - پەخشی هاوبەش لە ڕێگەی سێرڤەرە دەرەکییەکان (Vidmoly, Google Drive, Sharevids, YouTube).
  - **گۆڕینی سێرڤەر بە یەک کلیک** بێ ڕیفرێشکردنی لاپەڕە (سێرڤەر ١، سێرڤەر ٢...).
  - **دۆخی سینەما (Theater Mode)** و تاریککردنی ڕووناکی دەوروبەر (Lights Off).
  - **دەستنیشانکردنی لەکارکەوتنی سێرڤەر (Timeout detection)** دوای ١٢ چرکە و پێشنیارکردنی سێرڤەری دواتر.
  - سیستەمی ڕاپۆرتکردنی بەستەری لەکارکەوتوو (Broken Link Report).
  - دوگمەی پەخشی ئەڵقەی پێشوو / دواتر بۆ زنجیرەکان + دراوەری ئەڵقەکان + پەخشی خۆکار (Auto-play next).
- **داشبۆردی بەڕێوەبەر (Admin Panel)**:
  - ئامار و بینەران، ژمارەی فیلم و زنجیرە و ڕاپۆرتەکان.
  - بەڕێوەبردنی فیلمەکان بە هێنانی ئۆتۆماتیکی زانیاری لە **TMDB (One-click TMDB Auto-fill)**.
  - بەڕێوەبردنی زنجیرەکان و **زیادکردنی ئەڵقە بەکۆمەڵ (Bulk Add Episodes)** لە ڕێگەی دانانی لیستێک لە لینک.
  - ئامرازی تاقیکردنەوەی بەستەر (Link Tester) بە پێشبینینی ڕاستەوخۆ.
  - بەڕێوەبردنی ڕیزەکانی لاپەڕەی سەرەکی و ڕێکخستنە گشتییەکان.
- **لاپەڕە گشتییەکان**:
  - لاپەڕەی سەرەکی (Hero slider، بەشەکان، ڕیزەکان).
  - لاپەڕەی فیلمەکان و زنجیرەکان بە فلتەری ورد و گەڕانی زیندوو (Live Instant Search).
  - لاپەڕەی فیلم و زنجیرە بە تڕەیلەر، کورتەی چیرۆک، بەستەری داگرتن، و لێدوان.
  - لیستی دڵخوازەکان (Watchlist) و پڕۆفایلی بەکارهێنەر.
  - لاپەڕەکانی دەربارە، پەیوەندی، داواکردنی فیلم، مافی لەبەرگرتنەوە (DMCA Notice)، و یاساکان.

## 🛠 تەکنەلۆژیا و کەرەستەکان (Tech Stack)

- **فریمۆرک**: Next.js 14+ (App Router, Server Components)
- **شێوازکاری**: Tailwind CSS (Logical RTL properties: start/end/ps/pe)
- **داتابەیس**: PostgreSQL + Prisma ORM (لەگەڵ پشتیوانی SQLite بۆ تاقیکردنەوەی خێرای خۆجێیی)
- **ئاسایش و دڵنیابوونەوە**: NextAuth.js (Credentials Provider بە هشکردنی bcrypt)
- **ئایکۆنەکان**: Lucide React
- **پشکنین و پاراستن**: Zod, Provider Registry Allowlist, Strict CSP Frame-src

## 🚀 ڕێنمایی کارپێکردنی خێرا (Local Quick Start)

### ١. دامەزراندنی پێداویستییەکان:
```bash
npm install
```

### ٢. ئامادەکردنی بنکەدراوە و داتای سەرەتایی:
داتابەیسی بنەڕەتی لەسەر SQLite ڕێکخراوە تا بەبێ هیچ سێرڤەرێکی دەرەکی ڕاستەوخۆ کاربکات:
```bash
# دروستکردنی خشتەکان
npx prisma db push

# دابەزاندنی زانیاری سەرەتایی (١٢ فیلم و زنجیرە بە کوردی، ژەنەرەکان، و ئەکاونتی ئەدمین)
npm run db:seed
```

### ٣. دەستپێکردنی سێرڤەری گەشەپێدان:
```bash
npm run dev
```
ماڵپەڕەکە لەم ناونیشانە دەبێتەوە: [http://localhost:3000](http://localhost:3000)

## 🗄 گۆڕینی داتابەیس بۆ PostgreSQL (Neon / Supabase / VPS)

ئەگەر دەتەوێت ماڵپەڕەکە لەسەر PostgreSQL یان خزمەتگوزاری وەک Neon/Supabase/Render کارپێبکەیت:

1. فایلی `.env` بکەرەوە و ناونیشانی داتابەیسەکەت دابنێ:
   ```env
   DATABASE_URL="postgresql://user:password@ep-host.neon.tech/dima_cinema?sslmode=require"
   ```
2. فەرمانی گۆڕین جێبەجێ بکە:
   ```bash
   npm run use:postgres
   npx prisma db push
   npm run db:seed
   ```
*(بۆ گەڕانەوە بۆ SQLite لە هەر کاتێکدا، فەرمانی `npm run use:sqlite` جێبەجێ بکە).*

## 📋 پشکنینی تەواوی لاپەڕە و بەشەکان (Checklist)

- [x] سەرەکی (`/`): سلایدەری سەرەکی، ڕیزی ژەنەرەکان، ڕیزە چالاکەکانی ناو بنکەدراوە.
- [x] فیلمەکان (`/movies`): فلتەری ژانەرەکان، کوالیتی، ڕیزبەندی بەپێی نوێترین، زۆرترین بینراو، هەڵسەنگاندن.
- [x] زنجیرەکان (`/series`): لیستی زنجیرەکان، ژمارەی وەرزەکان، فلتەرەکان.
- [x] لاپەڕەی تەواوی فیلم (`/movie/[slug]`): باکدرۆپ، پۆستەر، تڕەیلەر، بەستەری داگرتن، لێدوان، فیلمە هاوشێوەکان.
- [x] لاپەڕەی تەواوی زنجیرە (`/series/[slug]`): گۆڕینی وەرزەکان، لیستی ئەڵقەکان، ماوە و بینین.
- [x] **پلیەری تایبەت بۆ فیلم** (`/watch/movie/[slug]`): گۆڕینی سێرڤەر بە خێرایی، دۆخی سینەما، تاریککردن، ئاگادارکردنەوەی کێشە، هاوبەشکردن.
- [x] **پلیەری تایبەت بۆ زنجیرە** (`/watch/series/[slug]/[episodeSlug]`): گۆڕینی ئەڵقەی پێشوو و دواتر، دراوەری ئەڵقەکان، بەردەوامبوونی خۆکار.
- [x] گەڕانی زیندوو (`Search Modal` & `/search`): گەڕان بە ناوی کوردی و ئینگلیزی بە ڕاستەوخۆیی.
- [x] بەشی دڵخوازەکان و پڕۆفایل (`/profile`): پاشەکەوتکردنی فیلم و زنجیرە بۆ هەژماری بەکارهێنەر.
- [x] چوونەژوورەوە و تۆمارکردن (`/auth/login`, `/auth/register`): سستمی ڕاستەقینەی NextAuth بە وشەی نهێنی پارێزراو.
- [x] لاپەڕە یاساییەکان (`/dmca`, `/about`, `/contact`, `/request`, `/privacy`, `/terms`).
- [x] داشبۆردی بەڕێوەبەر (`/admin`):
  - فیلمەکان: زیادکردن بە هێنانی TMDB، سێرڤەری پەخش، بەستەری داگرتن، تاقیکردنەوەی ڕاستەوخۆ.
  - زنجیرەکان: زیادکردنی وەرز، زیادکردنی ئەڵقە بەکۆمەڵ (Bulk-add).
  - ڕاپۆرتەکان: بینینی کێشەی سێرڤەر و چارەسەرکردن.
  - لێدوانەکان: پەسەندکردن و سڕینەوە.
  - ڕیزەکان: زیادکردن و ڕێکخستنی ڕیزەکانی لاپەڕەی سەرەکی.
  - تاقیکەرەوەی بەستەر (`/admin/link-tester`): تاقیکردنەوەی پەخشی هەر بەستەرێک پێش بڵاوکردنەوە.
