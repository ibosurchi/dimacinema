# ڕێبەری بەڕێوەبەری دیما سینەما (DIMA Cinema Admin Guide)

بەخێربێیت بۆ ڕێبەری تەواوی بەڕێوەبردنی سەکۆی **دیما سینەما (DIMA Cinema)**. ئەم بەڵگەنامەیە هەموو هەنگاوەکانی زیادکردنی فیلم، زنجیرە، سێرڤەرەکانی پەخش، و درێژکردنەوەی پێشکەشکارەکان ڕووندەکاتەوە.

---

## ١. چوونەژوورەوەی ئەدمین
- ناونیشانی داشبۆرد: `/admin` یان لە ڕێگەی مێنیوی سەرەوە
- ئیمەیڵ: `admin@dima.krd`
- وشەی نهێنی سەرەتایی: `Admin@123456`

---

## ٢. چۆنیەتی زیادکردنی فیلم (Add Movie)
1. بڕۆ بۆ **بەڕێوەبردنی فیلمەکان** -> دوگمەی **زیادکردنی فیلمی نوێ**.
2. **هێنانی ئۆتۆماتیکی (TMDB Auto-import)**:
   - گرتە لە دوگمەی **"هێنانی زانیاری لە TMDB"** بکە.
   - ناوی فیلمەکە بە ئینگلیزی بنووسە (بۆ نموونە: `Oppenheimer`).
   - ناوی سەرەکی، ساڵ، هەڵسەنگاندن، پۆستەر و باکدرۆپ بە یەک کلیک پڕ دەبنەوە.
3. ناوی کوردی و کورتەی چیرۆک بە کوردی بنووسە.
4. ژەنەرەکان دیاریبکە بە کلیک لەسەر ناوی ژەنەرەکان.
5. لە بەشی **سێرڤەرەکانی پەخشی ڕاستەوخۆ**:
   - دەتوانیت چەندین سێرڤەر دابنێیت (سێرڤەر ١، سێرڤەر ٢...).
   - دەتوانیت لە ڕێگەی دوگمەی **"تاقیکردنەوەی پەخش"** پێش بڵاوکردنەوە تەماشای ڤیدیۆکە بکەیت لەناو پلیەرەکە.
6. کلیک لەسەر **"بڵاوکردنەوەی فیلم"** بکە.

---

## ٣. دانانی بەستەری سێرڤەرە دەرەکییەکان (Vidmoly, Google Drive, Sharevids)
سیستەمی دیما سینەما **خۆکارانە (Auto-normalizer)** بەستەرەکان دەگۆڕێت بۆ کۆدی پەخشی پارێزراو. دەتوانیت هەر کام لەم شێوازانەی خوارەوە بنووسیت:

### أ. ڤیدمۆلی (Vidmoly):
- قبوڵ دەکرێت: لینکی تەواوی پەڕە `https://vidmoly.to/w/abc123xyz`
- یان کۆدی تەواوی ئایفرەیم: `<iframe src="https://vidmoly.to/embed-abc123xyz.html" ...></iframe>`
- سیستەمەکە خۆکارانە دەیگۆڕێت بۆ: `https://vidmoly.to/embed-abc123xyz.html`

### ب. گووگڵ درایڤ (Google Drive):
- قبوڵ دەکرێت: لینکی هاوبەشکردنی درایڤ وەک:
  `https://drive.google.com/file/d/1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs/view?usp=sharing`
- سیستەمەکە خۆکارانە دەیگۆڕێت بۆ فۆرماتی تایبەتی پەخشی درایڤ:
  `https://drive.google.com/file/d/1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs/preview`

### ج. شەیرڤیدز (Sharevids):
- قبوڵ دەکرێت: `https://sharevids.com/v/example` یان `<iframe src="...">`
- سیستەمەکە دەیگۆڕێت بۆ: `https://sharevids.com/embed/example`

---

## ٤. بەڕێوەبردنی زنجیرەکان و زیادکردنی ئەڵقە بەکۆمەڵ (Bulk Add)
لە لاپەڕەی زنجیرەکان، کلیک لە دوگمەی **ئەڵقەکان** بکە لەسەر زنجیرەی مەبەست:
1. **زیادکردنی وەرز (Add Season)**:
   - کلیک لە دوگمەی **"وەرزی نوێ"** بکە (وەرزی ١، ٢، ٣...).
2. **زیادکردنی ئەڵقەکان بەکۆمەڵ (Bulk Add)**:
   - دوگمەی زێڕینی **"زیادکردنی ئەڵقە بەکۆمەڵ (Bulk)"** دابگرە.
   - لینکەکانی Vidmoly یان Google Drive لە بۆکسەکە دابنێ؛ **هەر لینکێک لە دێڕێکی سەربەخۆدا**.
   - نموونە:
     ```text
     https://vidmoly.to/embed-ep1.html
     https://vidmoly.to/embed-ep2.html
     https://vidmoly.to/embed-ep3.html
     https://vidmoly.to/embed-ep4.html
     ```
   - کلیک لە **"زیادکردنی سەرجەم ئەڵقەکان"** بکە. سیستەمەکە ئۆتۆماتیکی ئەڵقەی ١، ٢، ٣، ٤ دروست دەکات و سێرڤەری هەر یەکێکیان پڕ دەکاتەوە!

---

## ٥. زیادکردنی پێشکەشکارێکی نوێ بۆ ڕێجستری (Provider Registry)
سیستەمی پەخشی دیما خاوەنی فایلێکی ناوەندییە بە ناوی:
`src/lib/player/providers.ts`

بۆ زیادکردنی هەر هۆستێکی نوێ (بۆ نموونە: Streamwish یان Doodstream)، تەنها ئەم چەند دێڕە زیاد بکە بۆ ناو `PROVIDER_REGISTRY`:

```typescript
streamwish: {
  id: "streamwish",
  name: "Streamwish",
  nameKurdish: "ستریم ویش",
  hostnames: ["streamwish.to", "streamwish.com"],
  sandbox: "allow-scripts allow-same-origin allow-presentation",
  allow: "autoplay; fullscreen; picture-in-picture",
  transformUrl: (url: string) => {
    // ئەگەر پێویستی بە گۆڕینی فۆرمات هەبێت
    return url.replace("/f/", "/e/");
  },
},
```
بە بێ هیچ دەستکارییەکی تر لە لاپەڕەکاندا، سێرڤەرەکە دەناسرێتەوە، لە فلتەرەکان کار دەکات و لەناو پلیەرەکە بە سەلامەتی پەخش دەکرێت.
